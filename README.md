# Aplikasi_dapur_mbg
Aplikasi web untuk mendukung operasional dapur produksi makanan bergizi gratis (program MBG), mencakup pencatatan pemesanan bahan baku hingga penerimaan barang. Dibangun untuk membantu tim dapur di berbagai lokasi mencatat dan memantau proses harian secara digital, menggantikan pencatatan manual berbasis kertas.

Cakupan Modul

- Manajemen Bahan Baku
  1. Pemesanan bahan baku (input kebutuhan harian/mingguan)
  2. Penerimaan barang & verifikasi jumlah masuk
  3. Pencatatan stok berjalan

- Pelaporan
  1. Riwayat transaksi harian per lokasi dapur
  2. Ringkasan penggunaan bahan baku

- Multi-lokasi
  1. Mendukung beberapa cabang dapur dalam satu sistem terpusat, dengan data yang terpisah namun dapat dipantau dari satu titik akses admin.

Lokasi Implementasi

Sistem telah diimplementasikan dan digunakan aktif di 6 lokasi dapur:

1. Dapur MBG Sadeng 1 — Semarang
2. Dapur MBG Sadeng 2 — Semarang
3. Dapur MBG Patean 1 — Kendal
4. Dapur MBG Patean 2 — Kendal
5. Dapur MBG Semanding — Tuban
6. Dapur MBG Bandongan — Magelang


- Tech Stack
1. Backend: PHP 8.2 | Laravel 8.0  
2. Frontend: Bootstrap 3.0
3. Database: MySQL
